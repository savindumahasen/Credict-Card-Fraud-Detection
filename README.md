# Credit-Card-Fraud-Detection
For development this project mainly use unsupervised learning.  This project mainly included k-means clustering, heirachial clustering, DBSCAN (Density Based Spatial Clustering of Application with Noise), and dimentionality reduction technique called PCA (Principle Component Analysis).

## K-means Clustering

This is the first algorithm, discussed in this project. K-means clustering algorithm  mainly use n_clusters parameter which defines the number of clusters. When we applying the K-means  clustering we have to  initialize the n_clusters  randomly. After performing  k-means clustering algorithm, we can identified the correct  n_cluster values.In this project I  initialize the number of clusters (n_clusters) as 2 at the first stage.
